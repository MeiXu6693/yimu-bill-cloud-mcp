## 本次发布

独立 MCP 现在可以自己完成扫码登录，不再要求使用方先准备 `YIMU_TOKEN`；DSH 插件模式保持不变。

### 重点

- 无 token 启动：MCP 正常启动并注册 3 个登录工具（`login_start` / `login_poll` / `logout`）。
- `login_start` 返回 PNG 二维码（MCP image content）和终端二维码（文字客户端可扫）；
  `login_poll` 成功后自动保存登录态，**不把 JWT 返回给模型**。
- 登录态保存到 `$XDG_STATE_HOME/yimu-bill-cloud-mcp/auth.json`（目录 0700、文件 0600），
  重启无需重新扫码；`logout` 删除本机登录态。只保存 token，不保存密码。
- 已配置 `YIMU_TOKEN` 时跳过登录工具，仍只暴露 11 个业务工具；DSH 插件始终走这条路径，行为不变。
- `--list-tools`：无 token 14 个（11 业务 + 3 登录），带 token 11 个。
- 新增 `qrcode` 依赖；导出工具清单与 CLI 测试同步更新。

### 安全

- token 泄露后官方网页退出不会使其失效；`logout` 只清本机，服务端 token 仍有效。
- 不保存密码；官方网页的「记住密码」是浏览器本地行为，不复刻。
